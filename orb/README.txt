Orb: Android-приложение (WebView + системная озвучка и распознавание речи).

Сборка:
1) Android Studio: File > Open > эта папка > Build > Build APK(s).
   APK: app/build/outputs/apk/debug/app-debug.apk
2) Без Android Studio: загрузите папку в репозиторий GitHub.
   Вкладка Actions > Build APK > скачайте orb-apk из Artifacts.
